# Traceveil identity

Use the continuous trace symbol with the Traceveil wordmark. The breaks and connected observations represent evidence across agent actions.

- Primary line: **Debug your coding agents.**
- Ink: `#0c1718`. Paper: `#f2f5ec`. Teal: `#0e7564`. Mint: `#96e3c2`. Warning: `#f0be63`.
- Use the light or dark wordmark on its supplied background. Keep clear space equal to one trace dot around the symbol.
- Minimum symbol size: 24 px. Use the monochrome source when only one ink is available.
- The banner and social card use labeled synthetic examples. They are illustrations, not screenshots or field-effectiveness claims.
- SVG files are editable source assets. Fonts use local Arial/sans-serif fallbacks and require no network.

Use a restrained terminal palette. Color supplements text labels. `NO_COLOR` disables color.
